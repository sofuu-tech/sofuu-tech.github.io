## 🔄 Troubleshooting

### The tool doesn't open
Make sure you have extracted all files from the ZIP archive if you downloaded that way. Double-clicking the HTML file should open it in your default browser. If it doesn't, try opening your browser first and dragging the HTML file into the browser window.

### Crosshair code doesn't work in CS2
Ensure you have copied the entire code. Sometimes extra spaces or missing characters can cause issues. Try generating a new code and copying it again. Make sure you are pasting into the correct field in CS2.

### The page looks broken
Your browser may be blocking certain features. Try using a different browser or ensure JavaScript is enabled. The tool requires JavaScript to function.
